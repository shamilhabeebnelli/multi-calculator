# EMI Calculator

Free client-side calculators and converters. No account, no server, no cost.

**Live:** https://multicalculator.denelli.in/
Mirror: https://shamilhabeebnelli.github.io/emi-calculator/

## Tools

- **EMI calculator**: monthly EMI, total interest, principal/interest split, year-wise amortization table. Processing fee and other charges fold into the down payment, optional insurance can be financed into the loan, and the full breakup exports to PDF.
- **Currency converter**: 23 currencies, INR rates from the keraladaily API (https://keralafortune.denelli.in/) with offline cache fallback
- **Bill splitter**: bill + tip split across people
- **Age calculator**: exact age, total days, weekday of birth, next-birthday countdown
- **Unit converter**: length, weight, temperature
- **AC electricity cost**: monthly cost from tonnage, usage hours and tariff

## Tech

Plain HTML/CSS/JS, no dependencies. Deployed to GitHub Pages by a GitHub
