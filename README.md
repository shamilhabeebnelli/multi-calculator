# Nelli Tools

Free client-side calculators and converters. No account, no server, no cost.

**Live:** https://shamilhabeebnelli.github.io/nelli-tools/

## Tools

- **EMI calculator** — monthly EMI, total interest, principal/interest split and year-wise amortization table
- **Currency converter** — 23 currencies, live INR rates pulled from [denelli-api](https://shamilhabeebnelli.github.io/denelli-api/) with offline cache fallback
- **Bill splitter** — bill + tip split across people
- **Age calculator** — exact age, total days, weekday of birth, next-birthday countdown
- **Unit converter** — length, weight, temperature

## Tech

Plain HTML/CSS/JS, no dependencies. Deployed to GitHub Pages by a GitHub
Actions workflow on every push.
